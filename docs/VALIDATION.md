# 1.0 重制版验证记录

## 最终统一验收（2026-11-13，修复后版本）

本节结果优先于下方第一轮记录。

### 检查发现并修复

1. 旧记录去重查询没有比较发件人，相同正文和取件码可能误伤不同发件人的包裹。已加入发件人条件。
2. 旧版记录没有去重摘要，删除、批量清理或清空后可能被补查重新加入。所有这些操作现在在同一事务中先保存摘要再删除。
3. 系统时间向前校正后再回调，补查起点可能晚于终点。已在时钟回调时重新检查最近 7 天。
4. 多个小组件广播并行时可能乱序刷新。已串行处理刷新并设置处理时限，移除阻塞式读取。

### 结果

- 16 项单元及数据库测试全部通过：4 项解析、7 项数据安全（含 20 个并发输入）、1 项旧数据库迁移、4 项短信补查（重复补查、撤权、失败不推进游标、时钟回调）。
- 3 项 Android 15 模拟器测试统一运行通过：短信解析入库/重复/删除，系统小组件双实例独立翻页及状态切换，界面复制/已取/筛选/恢复/删除。
- 小组件使用真实 AppWidgetHost、系统 RemoteViews 和 PendingIntent 执行点击；测试后删除临时 host，撤销临时绑定权限。未修改用户现有桌面。
- Debug、R8 Release 构建通过；Lint 为 0 errors，仍有资源与硬编码中文等 warnings。
- 小组件尺寸配置与布局 XML 和原版相同；git diff --check 通过。
- 最新 Debug 已覆盖安装到模拟器。交付目录中的 APK 与源码压缩包已更新为修复后版本。

### 仍需真机验证

运营商真实来信、长短信分片、双卡、不同厂商的锁屏过夜/重启策略仍未覆盖。系统 host 的小组件测试不代表所有厂商 launcher 都兼容。测试通过不能证明没有任何潜在 bug。
